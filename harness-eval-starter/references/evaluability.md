# 규칙 평가 가능성

사례를 쓰기 전에 실제 하네스 규칙의 출처, 적용 조건, 기대 행동, 실행 출력에서 볼 증거를 확인한다. 필드 형식과 수명 상태는 [schema.md](schema.md)를 따른다. `validate_golden.py`는 사례의 HARNESS Intent 연결, target에 있는 `rule_text`, 배치 크기 등을 검사한다.

- `INTENT_GAP`: 하네스 target이나 그곳의 실제 규칙이 없다. 규칙을 창작해 사례로 쓰지 않는다.
- `NEEDS_CLARIFICATION`: 규칙은 있으나 조건·기대 행동·관찰 증거가 모호하다. 사람이 확인할 내용을 카드에서 드러낸다.

조건과 증거가 명확한 사례만 DRAFT로 작성한다. 부족한 건수만큼 다른 후보를 자동 재추천하지 않는다. 한 배치 최대 4건, 누적은 무제한이다. 검수 후에는 승인 요청 블록을 내고 사람의 직접 입력으로만 승인한다.
